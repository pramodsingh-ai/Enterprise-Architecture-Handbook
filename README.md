# Enterprise Architecture Handbook for .NET Architects

> Building enterprise-grade applications using .NET, Azure, Microservices, Kubernetes and AI.

## Vision

This repository is a practical handbook for Software Engineers, Technical Leads, Solution Architects and Enterprise Architects.

The book uses a fictional enterprise platform called **NexusBank Platform** to explain architecture decisions through real-world scenarios.
